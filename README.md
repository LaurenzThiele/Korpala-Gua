# Korpala Gua: Indonesian Cave Database / Database Gua Indonesia

Exploration and documentation platform for Indonesian caves by **Korpala Universitas Hasanuddin**.

*Platform eksplorasi dan dokumentasi gua-gua Indonesia oleh **Korpala Universitas Hasanuddin**.*

**Live:** https://korpala-speleologi.netlify.app

---

## About / Tentang

Korpala Gua is an interactive cave mapping platform that documents cave locations, characteristics, and exploration data across Indonesia. Built to support research, exploration, and conservation of Indonesia’s karst landscapes.

*Korpala Gua adalah platform pemetaan gua interaktif yang mendokumentasikan lokasi, karakteristik, dan data eksplorasi gua-gua di seluruh Indonesia. Dibangun untuk mendukung kegiatan penelitian, eksplorasi, dan pelestarian kawasan karst Nusantara.*

---

## Features / Fitur

* **Interactive map / Peta interaktif**

  Visualize cave locations across Indonesia using OpenTopoMap.
  
  *Visualisasi lokasi gua di seluruh Indonesia dengan OpenTopoMap.*

* **Cave database / Database gua**

  Complete table with filtering, searching, and sorting features.
  
  *Tabel lengkap dengan filter, pencarian, dan pengurutan.*

* **Cave details / Detail gua**

  Information about depth, UTM coordinates, geographic region, cave type, and attached maps/documents.
  
  *Informasi kedalaman, koordinat UTM, wilayah geografis, jenis gua, dan peta/dokumen terlampir.*

* **Admin panel / Panel admin**

  Secure authentication system to add, edit, and delete cave data.
  
  *Tambah, edit, dan hapus data gua dengan autentikasi aman.*

* **Document uploads / Upload dokumen**

  Store cave maps in PNG, JPEG, PDF, or HTML formats.
  
  *Simpan peta gua dalam format PNG, JPEG, PDF, atau HTML.*
